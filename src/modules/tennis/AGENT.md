# Tennis module

- **id:** `tennis`
- **ring:** square (purpose tool — opens its own page)
- **page:** `tennis.html`, mounted by `entry.ts`
- **renderer:** dom

## Purpose

Truth of Tennis — five timeless, Product Owner-approved first-principle
pointers. No ages, phases, schedules, equipment lists, progression systems,
or footer. The page is static markup in `tennis.html`; `entry.ts` only tags
the runtime.

## Files

- `manifest.json` — module metadata (the manifest IS the registry).
- `entry.ts` — runtime marker.
- `icon.svg` — module icon.
